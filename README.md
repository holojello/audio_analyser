This is a C library for extracting time-based musical events (such as transient
onsets) from audio files. The results are outputed in a JSON file.

It is based on two preexisting libraries;
- [libsndfile](https://github.com/libsndfile/libsndfile): for audio file decoding
- [aubio](https://github.com/aubio/aubio/): for audio analysis
